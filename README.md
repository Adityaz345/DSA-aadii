## ⚙️ Getting Started

### Prerequisites

- [Java Development Kit (JDK)](https://adoptium.net/) installed
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/) or any Java IDE
- [Git](https://git-scm.com/) (optional, if you want to clone the repository)

Check that Java is available in your terminal:

```bash
java -version
javac -version
```

### Clone this repository

```bash
git clone https://github.com/Adityaz345/DSA-aadii.git
cd DSA-aadii
```

### Compile and run a Java program

For example, to run `AreaOfCircle.java` from the basics folder:

```bash
cd dsa_1_basics
javac AreaOfCircle.java
java AreaOfCircle
```

**Note:** The commands above assume the source file has no `package` declaration and that the class containing `main` is named `AreaOfCircle`. For another program, replace the filename and class name with the correct ones. Run commands from the directory appropriate for that program.
